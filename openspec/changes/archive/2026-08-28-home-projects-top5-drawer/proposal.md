## Зачем

Список проектов на главной странице сейчас разбит на страницы (по 8 элементов), из-за чего пользователю приходится кликать по пагинации, чтобы найти нужный проект среди остальных. Это неудобно и медленно, особенно когда проектов много.

## Границы изменения

### Входит

- на главной странице вместо постраничного списка отображаются первые 5 проектов;
- рядом с коротким списком — кнопка «Все проекты», по нажатию на которую открывается панель (шторка) справа во всю высоту экрана;
- в шторке — полный список проектов без пагинации, с прокруткой, и поле поиска, фильтрующее список на клиенте по названию проекта.

### Не входит

- виртуализация списка в шторке;
- поиск на сервере;
- изменения в API получения списка проектов.

## Функциональности

### Новые функциональности

- `home/project-browser`: краткий список из первых 5 проектов на главной странице и панель с полным прокручиваемым списком проектов и клиентским поиском по названию, открываемая по кнопке «Все проекты».

## Внешнее влияние

- пользовательский сценарий просмотра проектов на главной странице меняется: постраничная навигация заменяется коротким списком и панелью с прокруткой и поиском;
- внешние контракты (API) не затрагиваются.
