## Purpose

Функциональность позволяет пользователю быстро увидеть несколько проектов прямо на главной странице и при необходимости открыть полный прокручиваемый список со встроенным поиском по названию.

## ADDED Requirements

### Requirement: Краткий список проектов на главной странице

- **SHALL** главная страница отображает не более 5 первых проектов из списка, полученного от сервера.
- **MUST NOT** краткий список проектов на главной странице содержит постраничную навигацию.

#### Scenario: Проектов больше пяти

- **GIVEN** сервер вернул список из более чем 5 проектов
- **WHEN** пользователь открывает главную страницу
- **THEN** на странице отображаются первые 5 проектов из списка
- **AND** остальные проекты на странице не отображаются

#### Scenario: Проектов пять или меньше

- **GIVEN** сервер вернул список из 5 или менее проектов
- **WHEN** пользователь открывает главную страницу
- **THEN** на странице отображаются все полученные проекты

### Requirement: Открытие панели со всеми проектами

- **SHALL** главная страница отображает кнопку «Все проекты» рядом с кратким списком проектов.
- **SHALL** система при нажатии на кнопку «Все проекты» открывает панель, закреплённую у правого края экрана на всю высоту экрана.

#### Scenario: Открытие панели по кнопке

- **GIVEN** пользователь находится на главной странице
- **WHEN** пользователь нажимает кнопку «Все проекты»
- **THEN** система открывает панель со списком проектов у правого края экрана
- **AND** высота панели равна высоте экрана

### Requirement: Полный список проектов в панели

- **SHALL** панель отображает полный список проектов, полученный от сервера, без постраничной навигации.
- **SHALL** система позволяет прокручивать список проектов внутри панели, если он не помещается по высоте.
- **MUST NOT** список проектов в панели содержит постраничную навигацию.

#### Scenario: Список длиннее видимой области панели

- **GIVEN** панель со списком проектов открыта
- **AND** количество проектов превышает видимую высоту панели
- **WHEN** пользователь прокручивает список внутри панели
- **THEN** система показывает следующие проекты списка
- **AND** остальная часть страницы главной остаётся неподвижной

### Requirement: Поиск проектов внутри панели

- **SHALL** панель со списком проектов отображает поле поиска по названию проекта.
- **SHALL** система фильтрует отображаемый в панели список проектов на стороне клиента по совпадению введённого текста с названием проекта.
- **SHALL** система обновляет отфильтрованный список при каждом изменении текста в поле поиска.

#### Scenario: Поиск находит совпадения

- **GIVEN** панель со списком проектов открыта
- **AND** среди проектов есть проект, название которого содержит введённый текст
- **WHEN** пользователь вводит текст в поле поиска
- **THEN** система показывает в панели только проекты, название которых содержит введённый текст

#### Scenario: Поиск не находит совпадений

- **GIVEN** панель со списком проектов открыта
- **WHEN** пользователь вводит текст, которому не соответствует ни одно название проекта
- **THEN** система показывает в панели пустой список проектов

#### Scenario: Очистка поиска

- **GIVEN** панель со списком проектов открыта
- **AND** в поле поиска введён текст, сокращающий список
- **WHEN** пользователь очищает поле поиска
- **THEN** система показывает в панели полный список проектов
